# Notas Markdown V2

Notas continuam persistidas como conteúdo Markdown no workspace. Cada nota possui título independente e pode alternar entre **Raw** e **Formatado** sem alterar o texto original.

O modo formatado não interpreta HTML e bloqueia protocolos ativos, incluindo `javascript:` e `file:`. Links HTTP(S), `mailto:` e caminhos relativos são exibidos como links inertes. Títulos, checkboxes, listas, citações e blocos de código são renderizados localmente.

O histórico operacional de criação e atualização da nota continua sendo registrado pela camada de operações. Colagem de imagens gerenciadas, revisão explícita por arquivo e resolução de conflito em concorrência ainda não fazem parte deste incremento.
