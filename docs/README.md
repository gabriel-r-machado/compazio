# Documentation

This directory documents the current Compazio Community architecture and development workflow.
Historical compatibility code may still exist in the repository, but these documents describe the
community entry point and the behavior contributors should rely on.

- [Architecture](architecture.md) — code map, process boundaries and local trust model.
- [Development](development.md) — setup, checks, native modules and packaging.
- [Current capabilities](capabilities.md) — supported canvas, terminal, broker and coordination behavior.
- [Filesystem security](filesystem-security.md) — workspace containment and file import rules.
- [Portal security](portal-security.md) — remote-content isolation, permissions and MCP boundaries.
- [Architecture decisions](adr/) — durable design decisions and their rationale.

Repository-wide policies live at the root: [contributing](../CONTRIBUTING.md),
[security](../SECURITY.md), [code of conduct](../CODE_OF_CONDUCT.md) and
[trademarks](../TRADEMARKS.md).
