# Revisão de Diff V2

O modo **Diff** permanece dentro da Árvore de Arquivos. Ele lista arquivos modificados, permite stage/unstage e abre diff unificado limitado. Hunks são selecionáveis e enviados como contexto estruturado a um terminal conectado.

Descartar mudança não é exposto pela Fase 5 porque é uma operação destrutiva sem uma revisão visual completa. O usuário continua podendo concluir essa ação no Git local com total controle.
