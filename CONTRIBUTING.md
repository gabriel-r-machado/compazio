# Contributing

Bug fixes, tests, documentation and focused improvements are welcome. For a large
feature or architectural change, open an issue first to discuss the approach.

1. Fork the repository and create a branch.
2. Follow the [development guide](docs/development.md).
3. Add a regression test when fixing behavior. Run the checks relevant to your change.
4. Open a pull request explaining the problem, the change and what you tested.
   Include screenshots for visible UI changes.

Keep pull requests focused. Never include credentials, private workspace data or
unsanitized logs. Report vulnerabilities through [SECURITY.md](SECURITY.md).

Sign off your commits with `git commit -s` to certify the
[Developer Certificate of Origin](https://developercertificate.org/). Contributions
are made under the repository's AGPL-3.0-only license. Be respectful in issues and
reviews; see the [code of conduct](CODE_OF_CONDUCT.md).
